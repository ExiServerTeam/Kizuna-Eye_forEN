## 第69章: 学んだ教訓（追記2）

1. sudo 1.9.10+ はコマンド引数のワイルドカードを拒否する。可変引数が必要ならヘルパースクリプト方式にする。
2. visudo -c が失敗しても、tee で先にファイルが書かれていると壊れた sudoers が残る。visudo -f で書くか、tee 後に必ず検証する。
3. 監視対象の初見ファイルを無言でベースラインに吸収する設計は、新規作成の検知漏れになる。
4. パッチスクリプトの挿入行はインデントが崩れやすい。Go は通るが、gofmt -w で必ず整形する。
5. パス注入対策として、外部コマンドの出力から受け取るファイル名を厳格に検証する。
