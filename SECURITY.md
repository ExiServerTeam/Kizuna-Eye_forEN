# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.6.x   | ✅        |
| < 0.6   | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability, please send an email to
sy815twty@gmail.com. Do not open a public issue.

We will respond within 48 hours and provide a timeline for a fix.
